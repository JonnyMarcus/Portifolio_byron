# Semana 7 — Capacitação Trainee DPR | Byron Solutions

## 📌 Sobre

Registro dos estudos da **Semana 7** da capacitação trainee da área de **Desenvolvimento de Pessoas e Resultados (DPR)** da Byron Solutions, com foco em **React**, **Node.js** e **Next.js**.

## ⚛️ React

Estudo dos fundamentos da biblioteca React para construção de interfaces baseadas em componentes.

- Componentização e reutilização de código
- Props e composição de componentes
- Renderização e ciclo de vida de componentes

## 🟢 Node.js

Estudo do ambiente de execução JavaScript no lado do servidor.

- Fundamentos do runtime Node.js
- Módulos e ecossistema (npm)
- Execução de JavaScript fora do navegador

## ▲ Next.js

Estudo do framework Next.js, construído sobre o React, para aplicações web full-stack.

- Estrutura de rotas e páginas
- Renderização (SSR/SSG) e integração com React
- Diferenciais em relação a uma aplicação React "pura"
