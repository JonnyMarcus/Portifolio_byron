# Semana 1 — Capacitação Trainee DPR | Byron Solutions

## 📌 Sobre

Registro dos estudos da **Semana 1** da capacitação trainee da área de **Desenvolvimento de Pessoas e Resultados (DPR)** da Byron Solutions, com foco em **Git** e **GitHub**.

## 🔧 Git

- Controle de versão: `git init`, `add`, `commit`
- Branches e fluxo de trabalho colaborativo
- Resolução de conflitos

## 🐙 GitHub

- Repositórios remotos: `push`, `pull`, `clone`
- Pull requests e revisão de código
- Colaboração em equipe via plataforma

## 📖 Projeto prático

Criação de uma **história em grupo**, com cada integrante contribuindo através de commits e pull requests, aplicando na prática o fluxo colaborativo do Git e GitHub.
