# 📚 Git & GitHub

## 📖 Sobre

Este módulo foi desenvolvido com o objetivo de apresentar os fundamentos de versionamento de código utilizando Git e GitHub, ferramentas essenciais para o desenvolvimento de software moderno.

Ao longo da capacitação foram estudados conceitos relacionados ao controle de versões, colaboração em equipe, gerenciamento de branches e fluxo de trabalho utilizado em ambientes profissionais.

Além dos conteúdos teóricos, foi realizado um projeto colaborativo para aplicar na prática os conhecimentos adquiridos.

---

## 🎯 Objetivos

- Compreender os conceitos de versionamento de código;
- Aprender os principais comandos do Git;
- Utilizar o GitHub para hospedagem de projetos;
- Trabalhar com branches e fluxo de desenvolvimento;
- Gerenciar tarefas através de Issues;
- Realizar Pull Requests;
- Aplicar boas práticas de colaboração em equipe.

## 🚀 Projeto Desenvolvido

### 📖 História Colaborativa

Como atividade prática da capacitação, foi desenvolvido um projeto em equipe com o objetivo de simular um ambiente real de desenvolvimento.

A proposta consistiu na construção colaborativa de uma história fictícia utilizando Git e GitHub para gerenciamento das contribuições.

Durante o projeto foram utilizados:

- 🌿 Branches para desenvolvimento individual;
- 📝 Issues para organização das tarefas;
- 🔄 Pull Requests para integração das alterações;
- 👥 Trabalho colaborativo entre os participantes.

O foco principal da atividade foi praticar o fluxo de desenvolvimento utilizado por equipes profissionais de software.
