# ⚡ JavaScript

## 📖 Sobre

Este módulo teve como objetivo apresentar os fundamentos da linguagem **JavaScript**, explorando desde conceitos básicos de programação até recursos utilizados no desenvolvimento de páginas web interativas.

Durante a capacitação foram estudados tópicos essenciais da linguagem, manipulação do DOM, consumo de APIs e conceitos modernos utilizados no desenvolvimento front-end.

---

## 🎯 Objetivos

- Compreender os fundamentos do JavaScript;
- Trabalhar com variáveis, operadores e estruturas condicionais;
- Utilizar loops, arrays, objetos e funções;
- Manipular elementos HTML através do DOM;
- Entender conceitos de importação e exportação de módulos;
- Consumir APIs utilizando Promises e requisições assíncronas;
- Realizar exercícios práticos para fixação dos conteúdos.
