# 🎨 Tailwind CSS

## 📖 Sobre

Este módulo teve como objetivo apresentar os fundamentos do **Tailwind CSS**, um framework CSS utility-first utilizado para construir interfaces modernas, responsivas e altamente personalizáveis.

Durante a capacitação foram estudados conceitos de estilização, organização visual, responsividade e componentização, permitindo o desenvolvimento de interfaces de forma mais rápida e eficiente.

Os conhecimentos adquiridos foram aplicados na construção de uma Landing Page moderna utilizando Tailwind CSS.

---

## 🎯 Objetivos

- Compreender a filosofia Utility-First;
- Aprender a utilizar classes utilitárias;
- Desenvolver layouts responsivos;
- Construir interfaces modernas;
- Aplicar boas práticas de desenvolvimento front-end;
- Aumentar a produtividade na estilização de aplicações web.
