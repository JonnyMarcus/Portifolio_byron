# Semana 8 — Capacitação Trainee DPR | Byron Solutions

## 📌 Sobre

Registro dos estudos da **Semana 8** da capacitação trainee da área de **Desenvolvimento de Pessoas e Resultados (DPR)** da Byron Solutions, com foco em **React Hooks**, **manipulação e criação de formulários** e na biblioteca de UI **[shadcn/ui](https://ui.shadcn.com/)**.

## ⚛️ React Hooks

Estudo dos principais hooks do React e do gerenciamento de estado e ciclo de vida em componentes funcionais.

- `useState` — gerenciamento de estado local
- `useEffect` — efeitos colaterais e ciclo de vida
- Outros hooks nativos explorados durante o estudo

## 📝 Manipulação e criação de formulários

Estudo de como criar e controlar formulários em React, incluindo:

- Componentes controlados (`value` + `onChange`)
- Captura e validação de dados de entrada
- Envio (`submit`) e tratamento de dados do formulário

## 🎨 shadcn/ui

Exploração da biblioteca de componentes de UI **[shadcn/ui](https://ui.shadcn.com/)**, utilizada para construir interfaces com componentes reutilizáveis e estilizados (baseados em Radix UI + Tailwind CSS).
