# 📖 História Maluca — Git & GitHub

## 🚀 Sobre o Projeto

A **História Maluca** foi um projeto colaborativo desenvolvido durante a capacitação de **Git & GitHub** da EJ Byron.

O objetivo da atividade era simular um ambiente real de desenvolvimento de software, permitindo que os participantes aplicassem conceitos fundamentais de versionamento e colaboração através da construção coletiva de uma história fictícia.

Cada integrante ficou responsável por contribuir com partes da narrativa utilizando branches, issues e pull requests, praticando o fluxo de trabalho utilizado em equipes profissionais.

---

## 🎯 Objetivos

- Aprender os fundamentos do Git e GitHub;
- Trabalhar de forma colaborativa em um mesmo repositório;
- Utilizar Issues para gerenciamento de tarefas;
- Desenvolver funcionalidades em branches separadas;
- Integrar alterações através de Pull Requests;
- Simular um fluxo de desenvolvimento real.

---

## 📚 A História

A narrativa acompanha **Rusty**, um caranguejo desenvolvedor apaixonado pela linguagem Rust, criada por seu avô desaparecido, **Cobole**.

Determinado a descobrir o paradeiro de seu avô, Rusty embarca em uma aventura ao lado de seu melhor amigo, **Linus**, um pinguim com respiração aquática.

Durante a jornada, eles exploram os recifes mais distantes da Fenda do Biquíni, coletam fragmentos de códigos antigos, encontram servidores submarinos esquecidos e investigam um misterioso projeto chamado **Deep Blue**.

Ao final da aventura, Rusty descobre uma mensagem deixada por seu avô, revelando vestígios de seus estudos e incentivando o neto a continuar explorando os mistérios além das ondas.

---

## 🛠️ Conceitos Aplicados

### 🌿 Branches

Cada integrante desenvolveu sua contribuição em uma branch própria, permitindo que diferentes partes da história fossem criadas simultaneamente.

### 📝 Issues

As tarefas foram organizadas através de Issues, facilitando a divisão das responsabilidades e o acompanhamento das contribuições.

### 🔄 Pull Requests

As alterações eram enviadas por Pull Requests para revisão antes de serem integradas ao projeto principal.

### 👥 Trabalho Colaborativo

A atividade proporcionou experiência prática em comunicação, organização e colaboração utilizando GitHub.

## 🚀 Aprendizados

Durante o desenvolvimento deste projeto foram praticados conceitos fundamentais para o trabalho em equipe no desenvolvimento de software:

- Controle de versão com Git;
- Gerenciamento de repositórios remotos;
- Criação e gerenciamento de branches;
- Utilização de Issues;
- Fluxo de Pull Requests;
- Integração de alterações;
- Colaboração em equipe.

---

## 🏆 Resultado

Além de criar uma história divertida envolvendo programação, aventura e tecnologia, o projeto permitiu aplicar na prática o fluxo de desenvolvimento utilizado em empresas de software.

A atividade demonstrou como ferramentas como Git e GitHub facilitam a colaboração entre diferentes desenvolvedores em um mesmo projeto.
