# ⚛️ O que é React Native?

O **React Native** é uma biblioteca moderna, criada pelo Facebook, para a criação de aplicações nativas com JavaScript para **Android** e **iOS** a partir de **um único código**.

O grande diferencial em relação a tecnologias híbridas, como o Ionic Framework, é que **não existe um browser rodando junto com a sua aplicação**, então a performance não fica comprometida.

Gigantes da tecnologia como **Facebook, Instagram, Airbnb, Tesla** e vários outros já usam o React Native em seus projetos.

# 🛣️ Trilha de Aprendizagem

## 📚 Git & GitHub

Aprendizado sobre versionamento de código, gerenciamento de branches, colaboração em equipe, resolução de conflitos e fluxo de desenvolvimento profissional.

## ⚡ JavaScript & TypeScript

Fundamentos da linguagem, lógica de programação, funções, assincronicidade, consumo de APIs e tipagem estática para um código mais seguro.

## ⚛️ React Native & Expo

Criação de interfaces nativas com componentes, estilização, Hooks e gerenciamento de estado, usando o Expo para acelerar o desenvolvimento e os testes no celular.

## 🧭 Navegação

Construção de apps com várias telas, rotas, navegação em pilha, abas e passagem de parâmetros entre telas.

## 🔌 APIs & Dados

Consumo de APIs, tratamento de dados assíncronos, armazenamento local e organização de requisições.

## 🚀 Publicação

Geração de builds, configuração do app e processo de publicação na loja de aplicativos.
